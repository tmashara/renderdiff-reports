Pinned on both sides: clock starts at 2026-10-29T13:42:00.000Z on every load, a seeded Math.random, timezone UTC, locale en-US, light colour scheme, reduced motion, CSS animations and transitions off, videos kept from playing with video.js overlays hidden.

Unstable pixels — ones that changed between two shots of the same load — are painted magenta on both sides, counted on each card, and excluded from the measurement. A route more than 25% unstable is an error.

Magenta is also padding where one page is taller or wider than the other. It counts against the score on purpose — see the height delta on the row.
